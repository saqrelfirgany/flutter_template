# Devlog

Building this template in public, one small increment at a time.

## 2026-W30

Added a LICENSE file (MIT) and a License section in the README this week. Small change, but it was overdue — I've had people ask "can I actually use this in a real project?" and the honest answer was "probably, but nothing says so." A template without a license is legally ambiguous by default; people either skip it or fork it and hope for the best. MIT makes the intent explicit: use it, fork it, ship it, no permission needed.

Nothing in `lib/` changed this week. Sometimes the highest-value commit isn't code.

**Up next:** back to shipping actual pieces of the template — starting with a small, well-tested reusable form-field widget (validation logic + a widget test), not just another screen.
